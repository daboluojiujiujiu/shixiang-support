拾音隐私政策

拾音用于把你选择的录音和视频转成文字，或提取音频。默认使用本机识别，云端识别、润色、中文对照及 Obsidian 自动保存均由你选择开启。

开发者：Bo Wang。隐私与支持联系邮箱：137771579@qq.com。

1. 你选择的素材与本机处理

拾音读取你通过系统照片选择器选中的视频，或通过“文件”、语音备忘录及其他 App 主动提供的音视频。App 不扫描你的整个照片库，也不提供相机或麦克风录制功能。导入和处理不会删除你在照片、语音备忘录或文件提供方中的原始素材。

素材的导入副本、文字稿、提取的音频、处理记录和设置保存在 App 的设备存储中。系统备份可能包含这些本机数据。若素材来自 iCloud 或其他文件服务，素材下载由相应服务处理。

本机识别使用 Apple SpeechAnalyzer / SpeechTranscriber 在设备上处理，需要 iOS / iPadOS 26 或更新系统及受支持的设备和语言。首次使用可能需要下载 Apple 语言资源。音频提取也在设备上完成。开启云端处理时，另适用下述发送规则。

2. 可选的云端服务会收到什么

拾音没有内置开发者的私人 API 密钥或云端额度。你可以配置自己使用的 HTTPS 服务地址、兼容模型与密钥。语音服务推荐阿里云百炼，文字润色与翻译推荐 DeepSeek；这些均为可修改的推荐，不是使用要求。

  • 云端识别：向你配置的语音服务发送所选素材的声音、模型与处理参数，以及你填写的专有名词（如有且接口支持）。不会为语音识别上传原视频画面。使用百炼文件转写时，音频会先上传到该服务返回的阿里云对象存储地址，再由百炼处理。
  • 云端润色：向你配置的文字服务发送文字稿，以及用于辅助校对的参考标题、模型与处理指令。
  • 中文对照：向同一文字服务发送需要翻译的文字稿分段及相关上下文、模型与处理指令。
  • 连接测试：发送 App 内置的示例音频或示例文字；语音测试可能同时发送你配置的专有名词。测试会使用真实服务，可能产生费用。

云端请求由设备直接发送给你配置的服务及其提供的文件存储地址，拾音开发者不接收这些请求的音频、文字稿或 API 密钥。请求中的 API 密钥用于向相应服务认证，保存在本机钥匙串中。百炼对象存储上传使用服务提供的临时上传凭证，而不是账户 API 密钥。服务方还会收到建立网络连接所需的信息，例如 IP 地址。

云端音频、文字稿及相关上下文可能由服务方留存，并关联你的服务账户。账户标识用于认证、确定文件访问权限及提供功能。百炼当前临时上传文档说明文件有效期为 48 小时，随后自动清理；这不代表相关调用记录、结果和备份都在同一时刻删除。DeepSeek API 默认使用磁盘缓存，其文档说明不再使用的缓存通常在数小时至数天后清理。

除完成润色和翻译外，文字服务可能按照其适用条款和账户选择，将输入与输出用于模型训练或服务改进。DeepSeek 的现行条款包含这种可能用途；拾音不能保证每个账户均已退出，也不会替你变更服务账户中的选择。

具体保留期限、账户关联、训练用途和删除方式取决于你所选服务及账户的适用政策和设置。拾音无法保证任意兼容服务零保留、即时删除或不用于模型训练，也不能代为删除服务方已经收到的数据。授权前可查阅百炼隐私说明、百炼临时文件说明、DeepSeek 隐私政策及DeepSeek 缓存说明；使用其他服务时，请查阅相应提供方的政策和费用说明。

3. 授权与撤回

首次向相应服务发送音频或文字前，App 会说明接收服务与用途并征求允许。允许状态按具体服务地址及音频／文字用途保存；相同地址和用途之后会复用已保存的授权，更换地址或用途会再次询问。仅保存配置和密钥不会发起处理请求，也不会自动启用云端功能。

你可在“设置 → 关于与帮助 → 隐私与云端授权”撤回已保存的允许状态。之后新开启的云端任务会重新询问。撤回不会召回已发送的内容，也不会自动停止正在进行的任务；如需停止当前处理，请返回转写页面停止。

4. 分享与 Obsidian

主动分享文件时，你选中的 App 或服务会收到该文件。开启 Obsidian 自动保存后，新生成的文字稿会写入你选择的库文件夹。若该文件夹位于 iCloud 或其他同步目录，后续同步由相应服务负责，并受其政策约束。

你可以关闭自动保存，停止新的自动导出。已经分享或导出的副本仍需在目标 App、文件夹或同步服务中管理。

5. 保存与删除

  • 输出文件：文字稿和提取的音频保存在本机，直到你在“记录 → 转写文件”中删除或删除 App 的本地数据。仅删除／清空记录不会删除这些文件。
  • 待处理录音：分享导入的副本在失败或中断后可保留供重试；可在“收到的录音”中移除。处理成功后 App 会尝试清理该导入副本。
  • 密钥：在“设置 → 云端服务”中可移除当前配置服务的已保存密钥。曾更换服务地址时，需针对原地址管理原密钥；也可在服务提供方后台撤销密钥。卸载 App 不应被视为清除了所有钥匙串密钥。
  • 备份和外部副本：在系统中选择“删除 App”会移除其本地文件；“卸载 App”会保留文稿和数据。系统备份、云端备份、已导出文件、第三方已收到的数据需在相应系统或服务中分别管理。

拾音不要求注册 App 账户，当前版本不包含广告、分析或跟踪 SDK。可选云端处理仍会按第 2 节发送数据，因此不能把整款 App 描述为“任何情况下都不上传数据”。

7. 政策更新

功能或数据处理方式变化时，开发者应同步更新本政策、App 内说明及商店隐私信息。正式版本应在页面注明生效或更新日期。
